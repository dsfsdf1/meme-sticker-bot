# Фото → мемный стикер

Бот для личных чатов Telegram. Отправьте фото и получите стикер с прозрачным фоном и обводкой. Под результатом можно поменять цвет, выбрать мемную фразу или написать свою (до 80 символов). Бот отправляет статический WebP 512 × 512 как обычный Telegram-стикер. Подпись центрируется под вырезанным объектом и располагается в 8 пикселях от обводки.

## Запуск через Docker

1. Откройте [@BotFather](https://t.me/BotFather), выполните `/newbot` и получите токен для своего бота.
2. В этой папке выполните `cp .env.example .env`. Откройте `.env` и вставьте токен после `BOT_TOKEN=`. Храните его локально.
3. С установленным Docker Compose выполните:

   ```sh
   docker compose up --build -d
   docker compose logs -f bot
   ```

4. Откройте своего бота в Telegram, нажмите «Запустить» и отправьте фото обычным сообщением с изображением.

При первой обработке `rembg` скачает модель U²-Netp. После загрузки удаление фона выполняется на CPU, внутри бота. Бот очищает слабые края маски перед обводкой и уточняет её крупным планом, если объект занимает только часть кадра. Для запуска нужны исходящие подключения к Telegram, а для первой загрузки модели — к GitHub. Именованный том Docker хранит кэш модели и SQLite между перезапусками. Остановить бота можно командой `docker compose down`.

## Запуск без Docker

Нужен Python 3.12 или 3.13 и совместимая сборка ONNX Runtime для вашей платформы. Создайте `.env` с токеном, как описано выше, затем выполните:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m sticker_bot
```

В Linux для подписей установите DejaVu Sans Bold (в Debian/Ubuntu пакет `fonts-dejavu-core`). В macOS и Windows бот использует Arial Bold, если он доступен. Путь к своему шрифту с кириллицей можно задать через `STICKER_FONT`.

## Стикерпак из нескольких фото

1. В личном чате нажмите «Собрать стикерпак» или введите `/album`. Можно также сразу прислать альбом Telegram. Бот принимает от 3 до 8 фото одним альбомом или отдельными сообщениями в режиме сбора.
2. После загрузки бот покажет счётчик и кнопку «Посмотреть превью» под последними фото. Под сеткой будут номера стикеров. Нажмите номер, чтобы добавить подпись, повторить вырезание с более крупным кадром, оставить фото целиком в рамке или убрать кадр из черновика.
3. Вернитесь к обзору и нажмите «Сохранить стикеры». Выберите существующий набор или нажмите «Создать новый» и введите название. Ссылки на существующие наборы сохраняются.
4. Откройте `/pack` и выберите нужный набор, чтобы открыть его, скопировать ссылку через меню Telegram «Поделиться», переименовать набор или добавить в него ещё фото. Чтобы удалить стикер, отправьте его из своего набора в чат с ботом и ответьте на него командой `/remove`. В наборе должен остаться хотя бы один стикер.
5. Команда `/album` возвращает к текущему черновику. `/cancel` закрывает его. Сохранённый набор остаётся в Telegram. Незавершённый альбом хранится в памяти бота до 30 минут бездействия.

## Предложения от друзей

В `/pack` откройте набор и нажмите «Пригласить друзей». Отправьте ссылку человеку, от которого хотите получить стикер. Друг открывает ссылку, отправляет одно фото с необязательной подписью и подтверждает отправку под превью. Владелец видит стикер и выбирает «Добавить» или «Отклонить». Пропущенные предложения можно открыть через `/inbox`.

В SQLite хранятся список наборов, ссылки-приглашения и ожидающие решения предложения. Исходные фотографии предложений остаются в Telegram. Строка предложения удаляется из базы после решения владельца.

## Проверка в Telegram

1. Отправьте фото с человеком, животным или предметом. Проверьте прозрачный фон и белую обводку.
2. Под стикером нажмите «Обводка» и выберите другой цвет. В меню «Подпись» проверьте шаблон, свою фразу и удаление подписи. Каждый вариант приходит новым стикером.
3. Нажмите «Добавить в мой набор». Первый стикер создаёт набор «Мои мемные стикеры» на вашем аккаунте через Bot API. Следующие стикеры добавляются туда же. Проверьте кнопки «Открыть набор», «Поделиться набором» и «Поделиться ботом». Telegram предложит вам выбрать чат для отправки ссылки.
4. Введите `/settings`, смените цвет по умолчанию и отправьте новое фото. Команда `/pack` снова откроет меню набора, в том числе после перезапуска.

Обрабатываются фото до 10 МБ и 20 мегапикселей. За один раз бот обрабатывает одну операцию. Запускайте один экземпляр на токен. Выбранный цвет по умолчанию хранится в SQLite вместе с данными наборов и предложений. Текущий вырезанный объект, подпись и предпросмотр хранятся в памяти. Через 30 минут бездействия черновик недоступен и удаляется при следующем обращении к черновикам. В памяти помещается до 32 черновиков. После перезапуска отправьте фото снова. Набором управляет Telegram. Guest Mode оставлен для отдельного эксперимента.

## Автоматические тесты

```sh
python -m pip install -r requirements-test.txt
python -m pytest -q
```

Тесты проверяют WebP, обводку, подписи, маску, сбор и редактирование альбома, повтор сохранения и проверку владельца при удалении. Вызовы для создания и пополнения набора проверяются с подменой Telegram API. Токен не нужен.

Для дополнительной проверки с настоящей моделью запустите команду ниже. При первом запуске тест скачает модель в указанный каталог и обработает фотографию из `scikit-image`.

```sh
U2NET_HOME=data/models OMP_NUM_THREADS=2 TEST_REAL_MODEL=1 python -m pytest -q
```
