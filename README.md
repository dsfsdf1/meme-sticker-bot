# Фото → мемный стикер

Бот для личных чатов и мемов вашей беседы в Telegram. Отправьте фото и получите стикер с прозрачным фоном и обводкой. Под результатом можно поменять цвет, выбрать мемную фразу или написать свою (до 80 символов). Бот отправляет статический WebP 512 × 512 как обычный Telegram-стикер. Подпись центрируется над или под объектом, с выбранным отступом.

## Запуск через Docker

1. Откройте [@BotFather](https://t.me/BotFather), выполните `/newbot` и получите токен для своего бота.
2. В этой папке выполните `cp .env.example .env`. Откройте `.env` и вставьте токен после `BOT_TOKEN=`. Храните его локально.
3. С установленным Docker Compose выполните:

   ```sh
   docker compose up --build -d
   docker compose logs -f bot
   ```

4. Откройте своего бота в Telegram, нажмите «Запустить» и отправьте фото обычным сообщением с изображением.

При первой обработке `rembg` скачает модель U²-Netp. После загрузки удаление фона выполняется на CPU, внутри бота. Бот очищает слабые края маски перед обводкой и уточняет её крупным планом, если объект занимает только часть кадра. Для запуска нужны исходящие подключения к Telegram, а для первой загрузки модели — к GitHub. Именованный том Docker хранит кэш модели и SQLite между перезапусками. Остановить бота можно командой `docker compose down`.

## Запуск без Docker

Нужен Python 3.12 или 3.13 и совместимая сборка ONNX Runtime для вашей платформы. Создайте `.env` с токеном, как описано выше, затем выполните:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m sticker_bot
```

В Linux для подписей установите DejaVu Sans Bold (в Debian/Ubuntu пакет `fonts-dejavu-core`). В macOS и Windows бот использует Arial Bold, если он доступен. Путь к своему шрифту с кириллицей можно задать через `STICKER_FONT`.

## Свои фразы

Откройте /phrases или «Мои фразы» в главном меню. Добавьте до 10 фраз, каждую с новой строки, до 80 символов. Фразы сохраняются в SQLite и доступны после перезапуска. Под новым фото появится превью с несколькими вариантами подписей. Листайте варианты и выбирайте нужную. Подпись можно изменить, переместить или отменить правку как обычно. Эти же фразы доступны в редакторе кадров альбома.

## Найти момент в видео

Отправьте боту видео MP4, WebM, AVI, GIF или видеосообщение длительностью до 60 секунд и размером до 20 МБ. FFmpeg извлечёт выборку кадров, бот ранжирует их по резкости и освещению, уберёт близкие дубликаты и предложит до четырёх вариантов с примерными отметками времени. Это визуальный отбор кадров, распознавание эмоций в текущую версию не входит.

Выберите номер, затем «Выбрать этот кадр» — он откроется как обычный стикер со своими фразами и настройками. Также можно поправить и сохранить несколько моментов сразу. Для ручного запуска требуется установленный FFmpeg с ffprobe, например `brew install ffmpeg` на macOS или `apt-get install ffmpeg` на Debian/Ubuntu. Docker уже содержит FFmpeg.

## Мемы вашей беседы

Нажмите «Добавить в беседу» в главном меню или добавьте @FotoMemStickerBot в свою группу. В обычный личный диалог двух пользователей Telegram бот добавляется через создание группы.

Администратор включает механику командой `/group@FotoMemStickerBot`. Далее участники выбирают контекст сами:

- Ответьте `/phrase@FotoMemStickerBot` на реплику, чтобы сохранить её в общий словарь. Можно написать фразу после команды.
- Ответьте `/meme@FotoMemStickerBot` на фото или короткое видео. Бот создаст стикер в беседе. Под ним можно выбрать общую фразу. Текст после команды сразу станет подписью.
- Автор стикера может нажать «Редактировать и сохранить», перейти в личный чат и продолжить работу со стикером. Там будут доступны личные фразы и словарь этой беседы.
- `/phrases@FotoMemStickerBot` показывает общий словарь. Администратор удаляет фразы через `/unphrase@FotoMemStickerBot номер`.
- `/group@FotoMemStickerBot off` выключает механику в беседе.

При своём имени бота замените @FotoMemStickerBot на его username. Бот работает с командами и сообщениями, на которые они отвечают. История беседы автоматически не загружается и не анализируется. Стандартный Privacy Mode подходит, дополнительных прав администратора боту не требуется. Общие фразы, выбранные стикеры и ссылки перехода в редактор сохраняются в SQLite.

## Навигация и оформление

Под стикером доступны «Обводка», «Подпись» и «Расположение текста». Обводку можно отключить выбором «Без обводки». Подпись размещается сверху или снизу, с отступом 8 либо 24 пикселя. В `/settings` можно сохранить вариант без обводки для новых фото.

В меню есть кнопки возврата. «Отменить ввод» возвращает к предыдущему экрану без изменения подписи или названия. Кнопки «↶ Отменить правку» и «↷ Повторить правку» работают для последних десяти правок текущего стикера. Команда `/back` возвращает к редактированию, `/start` открывает главное меню с кнопкой продолжения черновика.

В альбоме доступны переходы к соседним кадрам. Исключённый кадр можно вернуть из обзора. Кнопка «Закрыть альбом» запрашивает подтверждение удаления черновика. Команда `/cancel` сразу закрывает редактирование.

## Стикерпак из нескольких фото

1. В личном чате нажмите «Собрать стикерпак» или введите `/album`. Можно также сразу прислать альбом Telegram. Бот принимает от 3 до 8 фото одним альбомом или отдельными сообщениями в режиме сбора.
2. После загрузки бот покажет счётчик и кнопку «Посмотреть превью» под последними фото. Под сеткой будут номера стикеров. Нажмите номер, чтобы добавить подпись, повторить вырезание с более крупным кадром, оставить фото целиком в рамке или убрать кадр из черновика.
3. Вернитесь к обзору и нажмите «Сохранить стикеры». Выберите существующий набор или нажмите «Создать новый» и введите название. Ссылки на существующие наборы сохраняются.
4. Откройте `/pack` и выберите нужный набор, чтобы открыть его, скопировать ссылку через меню Telegram «Поделиться», переименовать набор или добавить в него ещё фото. Чтобы удалить стикер, отправьте его из своего набора в чат с ботом и ответьте на него командой `/remove`. В наборе должен остаться хотя бы один стикер.
5. Команда `/album` возвращает к текущему черновику. `/cancel` закрывает его. Сохранённый набор остаётся в Telegram. Незавершённый альбом сохраняется в SQLite и доступен после перерыва и перезапуска. Команда /album открывает его снова.

## Предложения от друзей

В `/pack` откройте набор и нажмите «Пригласить друзей». Отправьте ссылку человеку, от которого хотите получить стикер. Друг открывает ссылку, отправляет одно фото с необязательной подписью и подтверждает отправку под превью. Владелец видит стикер и выбирает «Добавить» или «Отклонить». Пропущенные предложения можно открыть через `/inbox`.

В SQLite хранятся список наборов, ссылки-приглашения и ожидающие решения предложения. Для предложений хранятся идентификаторы файлов Telegram. Строка предложения удаляется из базы после решения владельца.

## Проверка в Telegram

1. Отправьте фото с человеком, животным или предметом. Проверьте прозрачный фон и белую обводку.
2. Под стикером нажмите «Обводка» и выберите другой цвет. В меню «Подпись» проверьте шаблон, свою фразу и удаление подписи. Каждый вариант приходит новым стикером.
3. Нажмите «Добавить в мой набор». Первый стикер создаёт набор «Мои мемные стикеры» на вашем аккаунте через Bot API. Следующие стикеры добавляются туда же. Проверьте кнопки «Открыть набор», «Поделиться набором» и «Поделиться ботом». Telegram предложит вам выбрать чат для отправки ссылки.
4. Введите `/settings`, смените цвет по умолчанию и отправьте новое фото. Команда `/pack` снова откроет меню набора, в том числе после перезапуска.

Обрабатываются фото до 10 МБ и 20 мегапикселей. За один раз бот обрабатывает одну операцию. Запускайте один экземпляр на токен. Выбранный цвет по умолчанию хранится в SQLite вместе с данными наборов и предложений. Черновик одиночного стикера, его подпись, параметры и история правок сохраняются в SQLite. В альбоме дополнительно сохраняются исходные кадры для повторного кадрирования. Через 30 минут освобождается кэш в памяти, при следующем обращении черновик загружается из базы. После перезапуска бот продолжает работу с теми же кнопками. /start позволяет вернуться к текущему черновику. Новый одиночный снимок заменяет предыдущий черновик, /cancel удаляет текущий черновик из базы. Набором управляет Telegram. Guest Mode оставлен для отдельного эксперимента.

## Автоматические тесты

```sh
python -m pip install -r requirements-test.txt
python -m pytest -q
```

Тесты проверяют WebP, обводку, подписи, маску, сбор и редактирование альбома, повтор сохранения и проверку владельца при удалении. Дополнительно проверяются сохранение и применение личных фраз, разделение словарей, ограничения видео, выбор разных кадров из настоящего MP4, переход из видео в редактор и права участников в группе. Для интеграционных тестов видео нужен FFmpeg; без него эти проверки пропускаются. Вызовы для создания и пополнения набора проверяются с подменой Telegram API. Токен не нужен.

Для дополнительной проверки с настоящей моделью запустите команду ниже. При первом запуске тест скачает модель в указанный каталог и обработает фотографию из `scikit-image`.

```sh
U2NET_HOME=data/models OMP_NUM_THREADS=2 TEST_REAL_MODEL=1 python -m pytest -q
```
